# Portada

Dual-extension scaffold for:
- Cloudstream
- Skystream

This repository is currently scaffold-only. No real sources/providers are added yet.

## Layout

- `cloudstream/`: Kotlin + Gradle plugin project for Cloudstream.
- `skystream/`: JavaScript plugin repository for Skystream.

## Current Status

- One placeholder Cloudstream plugin module: `Portada`.
- One placeholder Skystream plugin: `portada`.
- All runtime logic is intentionally no-op until source integration starts.
